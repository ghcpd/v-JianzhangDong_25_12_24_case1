Role & Objective:
You are an experienced prompt engineer. Your task is to read the attached conversation log and, based solely on all blocks starting with "User:", synthesize and generate a single English final prompt that can reproduce the original multi-turn results in a single interaction. Write this prompt to the file `final_prompt.txt`.

Inputs & Context:
- The conversation log is provided either as an attachment, pasted below, or by specifying a file path.
- Only process blocks that begin with "User:" at the start of a line (ignoring leading whitespace), as defined by the regex: ^\s*User:\s*
- All other role blocks (e.g., GitHub Copilot:, Assistant:, System:) must be completely ignored, including their content.
- The scope of a User block extends from its role marker line (inclusive) to the next role marker line (exclusive) or the end of the document.
- Ignore User blocks that only contain process control, confirmation, or abort instructions (e.g., "Continue", "OK", "Stop").
- If the first line of the document lacks a role marker, treat the first block as a User block.

Step-by-Step Instructions:
1. Parse the conversation log into blocks, identifying User blocks using the rules above.
2. Discard all non-User blocks and all User blocks that are process control/confirmation/abort instructions.
3. If, after filtering, only one substantive User block remains, write its content verbatim (in the original language) to `final_prompt.txt`.
4. Otherwise, extract requirements, constraints, preferences, and examples from all valid User blocks, resolving conflicts by keeping only the latest version of each requirement and removing any explicitly revoked or negated instructions.
5. Merge duplicate requirements and eliminate redundant statements.
6. Synthesize a single, concise, and comprehensive English prompt that enables a one-shot completion of the entire task, including all necessary sub-tasks.
7. Structure the final prompt as follows:
   - Role & Objective
   - Inputs & Context
   - Step-by-Step Instructions
   - Output Specification
   - Constraints & Preferences
   - Quality Gates (if applicable)
   - Place the most critical compliance instruction at the end
8. If no valid User block remains, write `ERROR: No valid user input found in the conversation log.`
9. If requirements are too vague or ambiguous, write `ERROR: Insufficient or ambiguous requirements. Please provide more specific instructions.`
10. If irreconcilable conflicts exist, write `ERROR: Conflicting requirements detected: [describe conflicts]`.

Output Specification:
- Write only the final English prompt to `final_prompt.txt` (UTF-8 encoding).
- Do not create, read, or modify any files other than for reading the input conversation log and writing `final_prompt.txt`.
- Do not output explanations, analysis, or any content except the final prompt.

Final Compliance Instruction:
At the end of the prompt, restate: "Write only the final English prompt to `final_prompt.txt` and do not output anything else."
